stale #camLayerBtn slot (no such element in index.html). Chip offsets retargeted to
52px steps, stale rules removed, nav-banner offsets mirrored by the same 52px shift.

device pixels), selector centers in DEVICE pixels:

topbar. The previous ~160 to 170 device px dead slot is gone.

## 2. Top-right dot (D2)

index.html: #gpsBtn removed, one locate affordance remains (#fromLocateBtn inside the
start field), contextual #recenterBtn stays hidden until navigation. The safety pill
keeps its dot but now always carries a text label, and its title/aria names the current
state and the tap action. Mode labels: Strict / Avoiding / Fastest.

Vision pass on docs/evidence/gw-ui-impl-20261020-after-main.png (vision_analyze), quoted:

- "There is no large dead gap between the hamburger/menu button and the first info
  chip, or between the chips themselves. The vertical spacing is fairly compact and
  consistent, roughly 25-30 px gaps."
- "It is a dark rounded pill containing a small teal dot and the readable white text
  Strict."
- "No separate crosshair/GPS/locate icon button in the top-right topbar."

## 3. Route flow without the locate precondition

src/main.js onRoute() now resolves the start itself when the start field is empty or
holds the "Your location" placeholder: it shows "Locating you..." and calls
currentLocationStart() (app.state.userLoc or cached fix, else one geolocation read with
an 8s budget), applies the fix to the map, then plans. If no fix is available it says
"Could not find your location. Type a start place, or allow location access." instead
of failing silently.
